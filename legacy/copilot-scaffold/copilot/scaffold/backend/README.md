This is a minimal FastAPI scaffold created by GitHub Copilot.

Quickstart:

- Create a virtualenv: `python -m venv .venv && .venv\Scripts\activate` (Windows) or `python -m venv .venv && source .venv/bin/activate` (Unix)
- Install dependencies: `pip install poetry && poetry install` or use `pip install -r requirements.txt` if you prefer.
- Run app: `uvicorn app.main:app --reload --host 127.0.0.1 --port 8000`
- Run tests: `pytest` (from `copilot/scaffold/backend`)
